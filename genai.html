Project Overview

GenAI — AI Interview Preparation Platform

GenAI is an AI-powered interview preparation platform that helps candidates prepare for job interviews using their resumes and target job descriptions. Users upload their PDF resume, provide a personal introduction and the target job description, and receive an AI-generated interview preparation report: candidate match score, technical and behavioral interview questions, skill gap analysis and a personalized 7-day preparation roadmap.

Problem Statement

Job seekers waste hours preparing for interviews with no personalized starting point

Job seekers spend hours searching for relevant interview questions, identifying their weak areas and building a study plan — most of it generic and not tailored to their profile or the role they are targeting. Without a structured, personalized plan, interview preparation is inefficient and easy to postpone.

Solution

GenAI automates interview preparation end to end

GenAI analyzes the user's resume and the target job description to compute a candidate match score, extracts technical and behavioral interview questions, identifies skill gaps, and generates a day-by-day preparation roadmap — all in one personalized, shareable report that users can save and download as a PDF.

Paste the full job description — required, up to 5,000 characters.

Report

Technical Interview Questions

Role-specific technical questions, each with an intention and a model answer to practice against.

Report

Behavioral Interview Questions

Behavioral questions with intentions and model answers for interview prep.

Report

Skill Gap Analysis

Skills from the job description the candidate is missing, tagged by severity — high, medium or low.

Report

Personalized 7-Day Preparation Roadmap

A day-by-day plan — focus areas and concrete tasks — tailored to the skill gaps.

Report

Interview Report Generation

"Generate My Interview Strategy" runs the AI analysis and opens the saved report. A PDF can be downloaded from the report page.

Storage

MongoDB-Based Report Storage

Reports are saved per user — the home page lists them with relative timestamps and you can return to any report later.

AI Integration

1

Upload & Paste

Resume (PDF/DOCX) and the target job description

2

Google Gemini AI

Analyzes the resume and job description server-side

3

Structured Report

Match score, questions, skill gaps and roadmap

4

Stored & Shared

Saved to MongoDB; downloadable as PDF

The frontend sends the inputs as multipart/form-data — jobDescription, selfDescription and the optional resume file — via Axios (withCredentials: true) to the backend. The backend calls Google Gemini and returns the structured report: matchScore, technicalQuestions (question / intention / answer), behavioralQuestions, skillGaps (skill / severity) and preparationPlan (7 days of day, focus and tasks). The report PDF is fetched as a blob from GET /api/interview/report/:id/pdf.

The frontend defaults to the backend at https://gen-ai-backend-opal.vercel.app/ when no override is configured.

Challenges and Learning

Integration

Separate frontend and backend repositories

GenAI is a full-stack app — the React frontend is maintained in its own repository, while the backend (Express, MongoDB, Gemini) lives in a separate repository. I therefore verified the actual feature set from the source and the live application instead of assuming a single repo, then adapted the verified screens into this static-site showcase without guessing at features.

Screenshots

Capturing genuine product screenshots

This environment had no built-in browser screenshot tool, so I captured the screens with headless Chrome driven via puppeteer-core against the deployed application — registering a throwaway account through the app's own sign-up flow, uploading the PDF, generating a report and screenshots of every screen. No stock images — the 7 images above are genuine captures of the live app.

UI & Design

Translating the AI report into clean sections

The report page packs a lot — match score ring, collapsible question cards, skill severity chips and a day-by-day roadmap. I broke it into focused, consistently proportioned sections (overview, problem, solution, features, tech, AI flow, gallery, challenges) that work in both dark and light themes and stay responsive from desktop to mobile.
