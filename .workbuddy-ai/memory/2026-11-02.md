# 2026-11-02 — Portfolio overhaul

## Restored the site
- `index.html` had been replaced by a broken React/Vite scaffold (`src/App.jsx` imported
  `./components/Layout` and `./pages/Home`, neither existed) → blank page. Restored the
  vanilla HTML from git HEAD and deleted the scaffold (`src/`, React deps, oxlint config).

## Bugs fixed
- Theme flash on reload: theme is now applied by an inline script in `<head>` before paint.
- Cursor glow never appeared if the pointer was already inside on load (now set on first move).
- `.feature-card` used `display:flex`, so the h4 and p sat beside the icon → switched to grid.
- Timeline dots were centred inside each card instead of on the centre line → anchored to the
  inner edge (`right:0` for left items, `left:0` for `.right`), with a mobile override at 7px.
- The contact-form loading spinner was permanently visible: SVG elements ignore the HTML
  `[hidden]` attribute, so `.btn-spinner[hidden]`/`.btn-icon[hidden]` now set `display:none`.
- Filter status said `Showing 7 projects in "all"` → now "Showing all 7 projects."
- `vite build` shipped no JavaScript (Vite only bundles module scripts). Added a
  `copy-classic-scripts` plugin in `vite.config.js` that emits `script.js` into `dist/`.

## Project screenshots (new)
- `scripts/capture-projects.mjs` drives local Chrome via `puppeteer-core` (no browser download)
  at 1280x800 and writes `assets/projects/<slug>-N.webp`. Run `npm run shots [-- slug]`.
- Login-gated sites are handled: HCM Lite signs in with the demo admin account, MaintainIQ
  clicks its public demo-account button; both skip login when the session cookie persists.
- Cards use a fake browser-chrome frame, cross-fade frames on hover (`shotCycle` keyframes,
  9s, 3 frames), and open a keyboard-accessible lightbox with thumbnails.
- Added HCM Lite (Saylani Hackathon) as project #1, plus live-demo links for HealthMate and
  E-Commerce that were missing. Total 7 projects.

## UI additions
Scroll-progress bar, tech marquee, back-to-top button, pointer spotlight on glass cards,
dark/light parity checked, mobile verified at 390px.
